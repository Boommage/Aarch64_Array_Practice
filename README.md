# Aarch64 Array Practice
 Simple program made in assembly that prompts the user for a number and initilizes an array of 56 or 53 integers based on if the entered number was even or odd respectfully. 

 That array same is displayed and then sorted before being displayed again along with displaying the arrays average.

# What I Learned
* How to properly utilize the stack in assembly.
* How to translate C control structures and logic into ARM64 assembly instructions
* The functional differences between general-purpose, special-purpose, and temporary registers
* How to use GDB (GNU Debugger) for stepping through and inspecting assembly programs
* The significance of calling conventions and register preservation across function calls
* How memory addressing works in low-level code (e.g. using ldr, str, and adr/adrp)
